# Apple styling reference

Source requested by the user: https://getdesign.md/apple/design-md (consulted 2026-11-14).

Implementation summary: use system typography, generous whitespace, restrained surfaces, clear navigation, large comfortable controls, subtly rounded utility cards, and visible focus states. Use 17px body text on web, semibold headings, and a spacing rhythm around 8px increments. Prefer native SwiftUI components, Dynamic Type, VoiceOver labels, safe areas, and light/dark system appearances on Apple devices. Respect reduced motion. Avoid decorative gradients and excessive shadows.

This reference describes Apple's marketing website, not a complete native HIG specification. Adapt its visual restraint to the clinical workflow instead of reproducing a storefront.

The project brief sets precedence: Apple interaction, accessibility, navigation and layout; AstraZeneca brand colors and appropriate typography. Use mulberry #830051 and magenta #d0006f with graphite #3c4242 and neutral surfaces. Do not invent logos or load unlicensed brand fonts. Use readable system fonts for clinical and patient controls.
